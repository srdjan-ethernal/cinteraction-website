CINTERACTION WEBSITE

Static HTML website based on Presentation Cinteraction.pdf.

Open index.html directly in a browser, or upload index.html and assets/ to your web hosting root. Keep the assets/ directory beside index.html.

The page uses standard HTML and embedded CSS. No JavaScript, framework, package installation or build step is required. Fonts are system fonts; all images are local.

All Demo buttons link to https://cinteraction.com/app/.
Contact links to office@cinteraction.com. Privacy links to the existing Cinteraction privacy page.

Content, team roles, event names and reported metrics follow the supplied presentation. The decorative bar chart in the hero is labelled as illustrative. The engagement timeline below the solution section is the platform screenshot from the presentation.

GitHub Pages: https://srdjan-ethernal.github.io/cinteraction-website/
Published from main, repository root. Updates pushed to main are published automatically.
